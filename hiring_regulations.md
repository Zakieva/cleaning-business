# Регламент оформления персонала: иностранные работники и самозанятые

Подробный внутренний регламент для клинингового ООО: как легально оформить иностранного гражданина по трудовому договору и как работать с самозанятыми исполнителями. Дополняет [операционный разбор](operations_guide.md) (разделы 1.3 и 4.2).

Правовая база и формы на октябрь 2026 года: 115-ФЗ «О правовом положении иностранных граждан», ТК РФ (гл. 50.1), 422-ФЗ (НПД), приказ МВД от 12.05.2026 № 290 (формы уведомлений), постановление Губернатора СПб от 05.12.2025 № 89-пг (региональные запреты). **Миграционное законодательство меняется несколько раз в год — перед каждым оформлением сверяйте формы и правила.**

# ЧАСТЬ 1. ИНОСТРАННЫЕ РАБОТНИКИ ПО ТРУДОВОМУ ДОГОВОРУ

## 1.1. Категории иностранцев: кого и как можно нанимать

| Категория | Документ для работы | Особенности найма |
|---|---|---|
| **Граждане ЕАЭС** (Беларусь, Казахстан, Армения, Киргизия) | Патент НЕ нужен | Нанимаются почти как граждане РФ; нужен миграционный учёт; уведомление МВД — обязательно |
| **Безвизовые страны СНГ** (Узбекистан, Таджикистан, Азербайджан и др.) | **Патент** на работу в СПб/ЛО | Основная категория в клининге; полный цикл проверок из этого регламента |
| **РВП / ВНЖ** | Патент не нужен | РВП — работа только в регионе выдачи; уведомление МВД обязательно |
| Временное убежище / беженцы | Патент не нужен | Уведомление МВД обязательно |
| Визовые страны | Разрешение на работу + квота | Для клининга нерентабельно — не используем |

**Региональные запреты СПб:** на 2026 год запрет на работу патентников действует для такси и курьерской доставки (ОКВЭД 49.32, 53.20.3x) — **клининг (81.21/81.22/81.29) под запрет не попадает**. Но Смольный ежегодно расширяет перечень (на 2027 обсуждаются торговля, фитнес, салоны красоты) — **проверять постановление губернатора каждый декабрь**.

**Важно про патент:** патент действует только в регионе выдачи (СПб и Ленобласть — это **разные** патенты!) и, если в патенте указана профессия, — только по ней. Работник с патентом Ленобласти на объекте в СПб = штраф до 1 млн ₽ по ч. 4 ст. 18.15 КоАП.

## 1.2. Проверка кандидата ДО оформления (чек-лист)

Проверку проводит директор (позже — ответственный за миграционный учёт, назначенный приказом). Ни один документ не принимается «на словах» — только оригиналы + копии в личное дело.

### Шаг 1. Базовые документы (все категории)

- [ ] **Паспорт** — срок действия, читаемость, соответствие фото. Копия всех заполненных страниц.
- [ ] **Миграционная карта** — цель въезда «работа» (для патентников обязательно), дата въезда, срок.
- [ ] **Миграционный учёт** («регистрация») — отрывная часть уведомления о постановке на учёт, актуальный адрес, срок не истёк.
- [ ] **ИНН и СНИЛС** — при отсутствии СНИЛС оформляет работодатель при приёме.

### Шаг 2. Проверка по реестру контролируемых лиц (РКЛ) — ОБЯЗАТЕЛЬНА

С февраля 2025 МВД ведёт реестр иностранцев без законных оснований пребывания (истёк срок, аннулирован патент, решение о выдворении). **Трудоустройство лица из РКЛ = штраф до 1 млн ₽.**

Порядок: сайт МВД (раздел «Реестр контролируемых лиц») или Госуслуги → ввести ФИО, дату рождения, серию/номер паспорта → **сохранить скриншот результата с датой** в личное дело. Данные обновляются каждые 4 часа; проверка бесплатна.

### Шаг 3. Для патентников — проверка патента

- [ ] Патент выдан на **Санкт-Петербург** (или ЛО — смотря где объекты).
- [ ] Профессия в патенте (если указана) совместима с работой («уборщик», «подсобный рабочий» и т.п.).
- [ ] **Все чеки об оплате авансовых платежей НДФЛ** — непрерывная цепочка с даты выдачи: пропуск оплаты = патент автоматически недействителен с этой даты, даже если выглядит «живым». Копии чеков — в личное дело, график следующих платежей — в календарь контроля.
- [ ] Срок действия патента (максимум 12 месяцев с даты выдачи, далее переоформление).
- [ ] Подлинность патента — проверка на сервисе МВД.

### Шаг 4. Для граждан ЕАЭС

- [ ] Паспорт + миграционная карта (кроме Беларуси) + миграционный учёт.
- [ ] Договор (полис) медстрахования — по действующим правилам работающие по трудовому договору попадают в систему ОМС; требование ДМС для трудовых договоров отменено, но для ГПХ и на «переходный» период до оформления уточняйте текущие правила.

### Стоп-факторы (не оформляем)

Кандидат в РКЛ; просроченная регистрация; разрыв в чеках патента; патент другого региона; миграционная карта с целью «частная»; документы «на проверке/переоформлении» без подтверждения. **Правило: сомнение = отказ.** Рынок труда дефицитный, но один нелегал стоит как годовая прибыль.

## 1.3. Оформление приёма — по шагам

**День 0 (до допуска к работе!):**

1. Собрать пакет (раздел 1.2), сделать копии, скриншот РКЛ.
2. **Трудовой договор** — по общим правилам ТК + гл. 50.1 ТК РФ:
   - по умолчанию **бессрочный** (срочный — только по основаниям ст. 59 ТК, «иностранность» — не основание);
   - обязательные доп. сведения: реквизиты патента (серия, номер, дата выдачи, срок) — для патентников; реквизиты полиса/условие о медпомощи — по категории;
   - место работы — субъект действия патента (СПб);
   - условие: действие договора приостанавливается/прекращается при окончании/аннулировании патента (ст. 327.5, 327.6 ТК).
3. Приказ о приёме, ознакомление с ПВТР и инструкциями под подпись, вводный инструктаж по охране труда (журнал).
4. **Медицинская книжка** — до допуска на объекты, где она требуется (пищевые производства, медучреждения, детские учреждения).
5. Подать **ЕФС-1 (сведения о трудовой деятельности)** в СФР — не позднее следующего рабочего дня.

**Дни 1–3 (критический срок):**

6. **Уведомление МВД о заключении трудового договора** — см. раздел 1.4. Без подтверждения подачи работник к клиентам не выходит.

## 1.4. Уведомление МВД — главный пункт регламента

- **Срок: 3 рабочих дня** с даты заключения договора (отсчёт со следующего рабочего дня после подписания). Тот же срок — при прекращении/расторжении.
- **Форма**: по приказу МВД от 12.05.2026 № 290 — **проверять актуальность формы перед каждой подачей**: уведомление на устаревшем бланке = то же нарушение, что и неподача (ч. 3 ст. 18.15 КоАП).
- **Касается всех категорий** иностранцев (ЕАЭС, патентники, РВП/ВНЖ, убежище) и **обоих типов договоров** — трудовых и ГПХ.
- Подаётся **на каждого работника отдельно** в территориальный орган МВД региона, где иностранец работает.
- Способы: **Госуслуги с УКЭП (рекомендуемый — остаётся электронное подтверждение)**, лично в МВД, через МФЦ, заказным письмом с описью.
- Хранить: копию уведомления + подтверждение подачи (квитанция Госуслуг/опись/расписка) — бессрочно в личном деле.
- С 01.10.2026 порядок зависит от статуса работодателя: у **юрлица** уведомления подаёт работодатель (наш случай), у физлица — сам иностранец. Нас это не освобождает ни от одного уведомления.

**Штраф за неподачу/просрочку/неверную форму (ч. 3, 4 ст. 18.15 КоАП, для СПб — повышенный): юрлицо — 400 тыс. – 1 млн ₽ за КАЖДОГО работника или приостановление деятельности на 14–90 суток; директор — 35–70 тыс. ₽.**

## 1.5. Контроль после приёма (ежемесячный регламент)

Назначить ответственного приказом (на старте — директор). Завести **календарь миграционного контроля** (таблица: работник / патент до / следующий чек до / регистрация до / РКЛ проверен):

| Периодичность | Действие |
|---|---|
| **Ежемесячно** | Проверка каждого иностранца по **РКЛ** (скриншот с датой в дело) |
| **Ежемесячно, за 5 дней до даты платежа** | Контроль оплаты очередного чека патента — запросить чек, копию в дело. Нет чека = **отстранение от работы в тот же день** (ст. 76 ТК) |
| За 30 дней до конца патента | Напомнить работнику о переоформлении; патент выдаётся максимум на 12 мес., переоформляется без выезда один раз |
| За 14 дней до конца регистрации | Контроль продления миграционного учёта |
| Ежегодно, декабрь | Проверка новых региональных запретов СПб (постановление губернатора) и изменений форм МВД |

**Если патент закончился/аннулирован:** отстранение (ст. 327.5 ТК) до 1 месяца; если документ не восстановлен — увольнение по ст. 327.6 ТК (специальное основание). Уведомление МВД о расторжении — 3 рабочих дня.

**Если предоставляете жильё работникам** — вы становитесь принимающей стороной: обязанность ставить на миграционный учёт (7 рабочих дней) и снимать при выезде. На старте проще не предоставлять жильё.

## 1.6. Налоги и взносы по иностранцам

| Категория | НДФЛ | Страховые взносы |
|---|---|---|
| Патентники | **13%/15% с первого дня** (как резиденты). Можно уменьшать НДФЛ на авансовые платежи по патенту: заявление работника + **уведомление из ФНС о праве на зачёт** (запрашивает работодатель, на каждый год) | Единый тариф как за граждан РФ (льгота МСП: пониженный тариф с выплат сверх порога — считает бухгалтерия) |
| ЕАЭС | 13%/15% с первого дня | Полностью как граждане РФ |
| РВП/ВНЖ | Как резиденты (при статусе) | Как граждане РФ |

Зарплата — на карту/счёт (безнал обязателен для валютного законодательства: выплата иностранцу-нерезиденту наличными — валютное нарушение со штрафом до 100% суммы). Зарплата не ниже региональной минимальной заработной платы СПб (31 250 ₽ с 01.01.2026 по региональному соглашению; федеральный МРОТ — 27 093 ₽).

## 1.7. Чек-лист самопроверки перед проверкой МВД

- [ ] На каждого иностранца: личное дело с копиями всех документов, скриншотами РКЛ, чеками патента.
- [ ] Все уведомления МВД поданы в 3-дневный срок, подтверждения в делах.
- [ ] Нет работников с патентами чужих регионов / просроченными чеками.
- [ ] Приказ об ответственном за миграционный учёт.
- [ ] Календарь контроля ведётся, отстранения оформлялись приказами.
- [ ] Трудовые договоры содержат реквизиты патентов; ЕФС-1 поданы.

# ЧАСТЬ 2. РАБОТА С САМОЗАНЯТЫМИ

## 2.1. Кто может быть самозанятым исполнителем

- Граждане **РФ** и стран **ЕАЭС** (Беларусь, Казахстан, Армения, Киргизия), а также Украины — регистрируются в «Мой налог» и платят НПД 6% с поступлений от юрлиц. **Граждане Узбекистана/Таджикистана самозанятыми быть НЕ могут** — для них только патент + трудовой/ГПХ договор (часть 1 регламента).
- Лимит дохода самозанятого — **2,4 млн ₽/год**; при превышении статус слетает, а ваши выплаты сверх лимита облагаются по-другому — контролируйте оборот ключевых исполнителей.
- **Запрещено** привлекать как самозанятого вашего **бывшего штатного работника в течение 2 лет** после увольнения — автоматическая переквалификация.
- **Иностранец-самозанятый из ЕАЭС = тоже уведомление МВД** о заключении/расторжении договора ГПХ в 3 рабочих дня (это требование не зависит от НПД!) + проверка по РКЛ. Многие на этом попадаются.

## 2.2. Оформление отношений — по шагам

**Шаг 1. Проверка статуса ДО договора и ПЕРЕД КАЖДОЙ выплатой.**
Сервис ФНС «Проверка статуса налогоплательщика НПД» (npd.nalog.ru/check-status) по ИНН на дату выплаты. Банковские сервисы выплат самозанятым (Точка, Т-Банк, Модуль — см. [выбор банка](bank_and_tax_selection.md)) делают это автоматически и не проводят выплату, если статус слетел. Используйте их — это снимает главный операционный риск.

**Шаг 2. Договор ГПХ на оказание услуг** (не «трудовой договор» и не его копия с заменёнными словами). Обязательные элементы:

- предмет — **конкретные услуги по уборке объектов по заявкам заказчика**, а не «выполнение функций клинера»;
- оплата — **за результат** (за выполненный заказ по согласованной стоимости), не «ежемесячное вознаграждение»;
- исполнитель **самостоятельно определяет способ выполнения**, вправе отказаться от заявки, вправе привлекать субисполнителей (или нет — но не прописывать подчинение);
- исполнитель применяет НПД, обязуется выдавать чек на каждую выплату и уведомить заказчика о снятии с учёта НПД в течение 1 дня (+ штрафная оговорка за нарушение);
- нет: графика работы, подчинения ПВТР, должности, отпуска, «зарплаты», материальной ответственности как у работника, запрета работать с другими заказчиками.

**Шаг 3. По каждому заказу — документы:**

1. Заявка (в мессенджере/CRM — фиксация объёма и цены) →
2. **Акт оказанных услуг** (можно реестром за неделю: дата, адрес/объект, услуга, сумма) →
3. Выплата на карту/счёт →
4. **Чек из «Мой налог»** — получить **сразу при выплате**; без чека выплата не подтверждена и не является вашим расходом на УСН «Д−Р».

**Шаг 4. Контроль чеков.** Самозанятый может **аннулировать чек** после получения денег (вы расход теряете, он налог не платит). Банковские сервисы выплат отслеживают аннулирования; при ручной работе — ежемесячная сверка чеков с реестром выплат.

**Хранение:** договор, акты, чеки, скриншоты проверок статуса — минимум 4 года (глубина налоговой проверки — 3 года + текущий).

## 2.3. Главный риск — переквалификация в трудовые отношения

ФНС автоматически скорит работодателей самозанятых (данные «Мой налог» + банки). Триггеры риска:

| Признак | Порог настороженности ФНС |
|---|---|
| Количество самозанятых у одного заказчика | 10 и более |
| Средняя выплата | ~35 тыс. ₽/мес и выше при постоянстве |
| Продолжительность сотрудничества | 3+ месяца непрерывно |
| Доля вашего юрлица в доходе самозанятого | ближе к 100% — главный маркер |
| Регулярность выплат | одинаковые суммы 2 раза в месяц «как зарплата» |
| Массовая регистрация НПД | исполнители зарегистрировались за день до договора |

Признаки трудовых отношений из судебной практики: закреплённый график и смены, подчинение регламентам как ПВТР, форма с логотипом как обязанность, инвентарь и химия только заказчика, контроль процесса (а не результата), невозможность отказаться от заказа, единственный заказчик годами.

**Последствия переквалификации:** доначисление НДФЛ 13% + страховых взносов ~30% со ВСЕХ выплат за 3 года + пени + штраф 40% (умышленность) + штрафы по ст. 5.27 КоАП (до 100 тыс. ₽ за каждого) + постановка на учёт как недобросовестного работодателя. На 10 исполнителях с оборотом 300 тыс. ₽/мес это **5–7 млн ₽** — смертельно для малого бизнеса.

## 2.4. Правила гигиены (как работать и не попасть)

1. **Экономическая реальность важнее бумажек**: если по сути это сотрудники со сменами — никакой договор не спасёт. Модель должна реально быть сдельной: исполнитель видит заказ → принимает или отказывается → получает % от чека.
2. Выплаты — **по фактическим заказам**, суммы разные, частота привязана к заказам (у нас еженедельно по реестру выполненного — это нормально, суммы при этом плавают).
3. Не оформляйте самозанятыми диспетчера, бригадиров с управленческими функциями, супервайзера — у них трудовая функция, а не услуга. **Комбинированная модель**: администраторы в штате, клинеры-сдельщики на НПД.
4. Пусть исполнители работают и с другими заказчиками (не запрещайте в договоре; подработка у конкурентов неприятна, но запрет = признак трудовых отношений).
5. Форма/бейдж — «предоставляется для допуска на объекты», а не «обязательная униформа»; химия — можно продавать/передавать по акту, можно компенсировать — главное, не воспроизводить «работодатель всё выдал, работник обязан».
6. Обучение — «вводный инструктаж по стандартам заказчика и техбезопасности» (допустимо), а не «аттестации и повышение квалификации сотрудников».
7. При росте (10+ постоянных исполнителей, 150+ тыс. ₽/год на человека) — переводите костяк в штат: взносы по тарифу МСП не так страшны, как доначисления; смешанная структура (ядро в штате + сдельный резерв на НПД) ещё и снижает скоринговые триггеры.
8. Раз в квартал — самоаудит по таблице триггеров из 2.3.

## 2.5. Сравнение форматов (сводная)

| Параметр | Штатный (трудовой) | Самозанятый (НПД) | ГПХ с физлицом без НПД |
