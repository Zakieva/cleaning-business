# Клининговое ООО в Санкт-Петербурге (стратегия: только B2B)

Пакет материалов для запуска клининговой компании в СПб: от регистрации ООО до финансовой модели. **Выбранная стратегия — работа только с юрлицами**: разовые услуги (генеральные уборки, послестрой, окна), регулярные контракты на уборку офисов и коммерческих объектов, субподряд у FM-операторов. Уборка квартир для частников (B2C) не делается.

Подготовлено: октябрь 2026. Все цифры основаны на открытых источниках (ФНС, BusinesStat, АКФО, Коммерсантъ, прейскуранты компаний СПб) — ссылки внутри документов.

## Главные выводы

- Рынок клининга СПб — **≈28 млрд ₽ в год** (2025, оценка по выручке юрлиц с основным ОКВЭД 81.22; без ИП и самозанятых реальный объём выше). Второй рынок страны после Москвы. Крупнейшие по выручке за 2025 в широкой отрасли уборки — АО «Коломяжское» (4,36 млрд ₽, уборка улиц по госконтрактам), ООО «ГБР» (2,53 млрд ₽ — крупнейший именно в клининге помещений, ОКВЭД 81.22), АО «Автодор» (2,25 млрд ₽, содержание дорог); рынок фрагментирован.
- Прибыльность зависит от продукта и стадии: разовые B2B-услуги (генеральные, послестрой) — маржа до вычета накладных ~45–50%, регулярные контракты — 25–35%, субподряд — 15–25%; по компании в целом реалистично **0–10% в первые месяцы и 20–25% при загрузке**. Крупные тендеры — 1–5% из-за демпинга.
- Стратегия входа в B2B: разовые услуги юрлицам по предоплате (быстрые деньги) + субподряд у FM-операторов (загрузка) → конвертация в регулярные контракты малых офисов с прямыми договорами. Тендеры 44-ФЗ — только с репутацией и оборотом.
- Главное ограничение — **персонал и оборотный капитал**: медианная предлагаемая зарплата клинера в СПб 64 тыс. ₽, дефицит кадров, высокая текучка; зарплаты платятся еженедельно, контракты платят через 10–45 дней — без резерва в 1,5–2 ФОТ контрактную модель не вытянуть.
- Реалистичный ориентир: стартовые вложения 265–585 тыс. ₽ (включая оборотный резерв), безубыточность — 2 контракта + 4–5 разовых заказов в месяц, целевая прибыль 120–160 тыс. ₽/мес на портфеле из 4–6 контрактов и потока разовых услуг.
